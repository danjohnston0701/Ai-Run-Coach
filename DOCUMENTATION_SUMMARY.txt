📋 KEY FINDINGS
================================================================================

GPS Configuration
  - Request interval: 1000ms (matches Garmin watch frequency)
  - Fastest accept: 500ms (allows faster updates if available)
  - Uses FusedLocationProviderClient (Google Play Services)
  - Includes altitude and bearing when available

Power Management
  - PARTIAL_WAKE_LOCK keeps CPU awake, allows screen sleep
  - Prevents deep sleep during GPS tracking
  - 10-hour automatic timeout as safety measure
  - Released on run end or service destruction

Permissions
  - Requires either FINE or COARSE location (not both)
  - Optional: Activity recognition, body sensors
  - Users can "Continue to App" without optional permissions
  - Manifest-only: FOREGROUND_SERVICE, WAKE_LOCK

Elevation Noise Filtering
  - Phone GPS: ±5-10m accuracy, needs 60-second window
  - Garmin GPS: ±1m accuracy (barometric fusion), needs 20-second window
  - Different thresholds prevent false positives from GPS jitter
  - 3% grade minimum to separate real hills from noise

Coaching Audio Gaps
  - Global minimum: 15 seconds AND 150m between cues
  - Navigation: 8 seconds (shorter, safety-critical)
  - Km split buffer: 200m exclusion zone
  - Prevents audio spam while maintaining responsiveness

Watch GPS Priority
  - 15-second window after last watch GPS update
  - Skips phone GPS during this window (watch more accurate)
  - Prevents double-counting distance and pace calculations
  - Provides headroom for Bluetooth latency spikes

🔍 IMPLEMENTATION HIGHLIGHTS
================================================================================

✨ Sophisticated Elevation Processing
   - Different noise windows for phone (60s) vs. Garmin (20s)
   - Reduces GPS jitter (±1-10m) to ±0.5-1.3m RMS
   - Prevents false positives from random jitter on flat terrain
   - Validates with both elevation change AND grade percentage

🎯 Smart Multi-Source GPS Arbitration
   - Automatically switches between phone and watch GPS
   - Maintains 15-second priority window for watch data
   - Ensures most accurate source is used
   - Prevents duplicate distance counting

🔐 Android 12+ Compliance Workaround
   - Problem: Can't call startForegroundService() from background
   - Solution: Pre-start service while app in foreground
   - Shows "Watch Ready" notification in standby state
   - Seamlessly transitions to background-safe mode

🎨 Graceful Permission Handling
   - Either fine or coarse location is acceptable
   - Sensors are optional (HR, step counter)
   - App continues without optional permissions
   - Users see what they're granting, can proceed anyway

📍 Location Data Comprehensive
   - 9+ fields per update: lat, long, time, speed, altitude, bearing, HR, cadence, grade
   - Tracks accuracy (CEP in meters) for each point
   - Stores minimum/maximum values per session
   - Supports time-series data for graphs and analysis

🔄 Data Persistence On Network Loss
   - Local sync queue prevents data loss
   - Queued data uploads when network restored
   - No data loss during coverage gaps or airplane mode
   - Automatic retry logic with exponential backoff
