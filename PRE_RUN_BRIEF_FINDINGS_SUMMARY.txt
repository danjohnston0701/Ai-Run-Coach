4. ✅ COACH MESSAGING BEFORE RUN
   ──────────────────────────────────
   
   TWO-PHASE COACHING SYSTEM:
   
   PHASE 1: PRE-RUN (Before user starts)
   ───────────────────────────��────────
   Location: server/session-coaching-service.ts (lines 308-441)
   
   • generateSessionInstructions()
     - Fetches runner profile (athletic grade, fitness level, history)
     - Fetches session context (type, goal, intensity, duration)
     - Fetches last run coaching insight (previous feedback)
   
   • AI Tone Determination (lines 90-149)
     - Analyzes runner + session + history
     - Returns: optimal tone, intensity, encouragement level
     - Can override user preference for specific sessions
   
   • AI Brief Generation (lines 353-409)
     - Prompt asks: "Write a specific, motivating pre-run briefing"
     - System: elite running coach perspective
     - Returns: 2-4 sentence, session-specific coaching message
   
   PHASE 2: REAL-TIME (During run)
   ─────────────────────────────────
   • Uses phase-based coaching statements
   • Triggered by: km splits, pace, HR, effort
   • Subject to 90-second cooldown between non-milestones

6. ✅ AI BRIEF GENERATION DETAILS
   ────────────────────────────────
   
   INPUTS ANALYZED:
   • Runner: athletic grade, fitness, experience, preferences, history
   • Session: type, goal, intensity, duration, distance, intervals
   • Context: last run feedback, coach recommendations, adaptation allowed
   
   AI OUTPUTS:
   • preRunBrief: "2-4 sentence motivating brief specific to this session"
   • sessionStructure: phases with targets and coaching triggers
   • aiDeterminedTone: optimal tone choice (8 options available)
   • coachingStyle: encouragement level, detail depth, technical depth
   • toneReasoning: explanation of why this tone was chosen
   
   TONE OPTIONS:
   - light_fun
   - direct
   - motivational
   - calm
   - serious
   - playful
   - instructive

7. ✅ COACHING COOLDOWN SYSTEM
   ─────────────────────────────
   
   File: server/coaching-cooldown.ts (202 lines)
   
   MILESTONES (Always Fire):
   • Km splits (honors user's split interval setting)
   • 500m check-in (first 500m)
   • Final 500m, Final 100m
   • Interval transitions
   • Navigation turns
   
   NON-MILESTONES (Subject to Cooldown):
   • Phase coaching
   • Effort coaching
   • Pace deviation
   • HR coaching
   • Cadence coaching
   
   COOLDOWN TIMES:
   • 90 seconds between non-milestone cues
   • 45 seconds of silence after any milestone
